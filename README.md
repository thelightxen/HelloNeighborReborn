
# HelloNeighborReborn: Code (DevKit)


#### What kind of DevKit is this?
This can be considered a kind of continuation of Hello Neighbor modding, but in Old Art Style.
This is almost a 1:1 Mod Kit made from scratch. **But better and more optimized.**

##### What does the project include?
- **Full AI customization:** you can write your own complex tasks on blueprints. ✅
- Smart self-learning AI ✅
- Old Art Style Vibes of 2016 ✅
- You can even create your OWN FAN GAME ✅
- And much more...
